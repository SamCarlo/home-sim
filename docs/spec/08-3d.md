# 08 — 3D (three.js)

The look is **friendly low-poly**: flat-shaded shapes, soft colors, simple procedural textures. The goal is charm and
clarity on a Chromebook, not realism.

## 1. Basics

- three.js is vendored and pinned (`app/vendor/three/`). Import `three` and `three/addons/…` through the import map.
- **Units**: 1 unit = 1 foot. Y is up, the ground is y = 0, and the front of the lot faces +Z (toward the default camera).
- Every `three/*` module is browser-only and loaded lazily (`import('../three/scene.js')`).

## 2. Scene (`three/scene.js`)

`createScene(container, { biome, landmark, monthIndex, timeOfDay = 0.62, interactive = true }) →`
```js
{ scene, camera, renderer, controls,
  setTimeOfDay(t),          // 0..1: 0.25 sunrise, 0.5 noon, 0.75 sunset; night outside [0.22, 0.80]
  setSeason(monthIndex),    // snow, fall color
  add(obj), remove(obj), frame(box3, {padding}),   // camera fit
  requestRender(), start(loopFn), stop(), dispose() }
```
- **Renderer**:
  - `antialias: devicePixelRatio <= 1.5`, `setPixelRatio(Math.min(devicePixelRatio, 1.5))`;
  - `outputColorSpace = SRGBColorSpace`, ACES filmic tone mapping (exposure ~1.0);
  - `shadowMap.enabled`, `PCFSoftShadowMap`.
- **Camera**: perspective at 45°, framed on the home. **OrbitControls**:
  - damping on;
  - polar angle limited to 15–80° (never under the ground);
  - zoom limited to 0.5×–2.5× of the framing distance;
  - pan limited to the lot.
- **Render on demand**: render on control change, resize (ResizeObserver) and `requestRender()`. `start(loopFn)` runs a
  RAF loop only while something animates. It pauses when `document.hidden`.
- **Dispose** frees geometries, materials, textures and the renderer when the screen unmounts.
- **WebGL fallback**: if context creation fails, show the Phase 1 SVG preview of the home plus "3D isn't available on this
  device — the game still works." The game stays fully playable, because 3D is only visual.

## 3. Sky, light, time and seasons (`three/sky.js`, `terrain.js`)

- **Light**: a hemisphere light for sky/ground fill plus one directional **sun** that casts shadows (1024² map, shadow
  camera fitted to the scene bounds).
- **Sky**: a big back-side sphere with a vertical gradient. `setTimeOfDay(t)` moves the sun along an arc (east to
  west over the lot) and blends through these palettes:
  - night: deep navy with stars (points);
  - dawn: peach/pink;
  - day: the biome's sky blue;
  - dusk: orange/purple.
  - Sun intensity follows the elevation. At night a dim blue moonlight comes up, and `nightFactor` (0–1) drives window glow.
- **Terrain** (a 400 × 400 ft ground plus biome decorations):

  | Biome | Terrain |
  |---|---|
  | tropical-wet | deep green with fern/jungle clumps (Pāhoa: black lava patches) |
  | tropical-dry | tan grass, black lava rock, ocean edge |
  | tropical-upland | rolling green pasture, ranch fence |
  | tropical-urban / temperate-urban | asphalt and sidewalk grid |
  | temperate-rain | green with conifers |
  | subtropical-* | green lawn with oaks/palms |
  | desert / desert-mountain | sand/ochre ground with cacti, agave and rocks |
  | plains | yellow-green grass, very few trees |
  | alpine | meadow, pines, distant mountains |
  | continental-* / humid-forest | lawn with maples/birches |
  | maritime / subarctic-coastal | rocky shore and water |

  - Coastal places (Honolulu, Kona, Miami, Halifax, Homer) get a water plane along one edge.
  - The landmark from `04` §7 appears as a low-poly backdrop silhouette.
- **Seasons**: `setSeason(monthIndex)` turns the ground white and puts snow caps on roofs during `location.seasons.snowMonths`,
  and gives deciduous trees fall colors during `fallColorMonths`. Hawaiʻi stays green all year (optional: snow on Maunakea in winter).

## 5. The home contract (every generator returns this)

```js
{ object,            // THREE.Group, origin = lot center at ground level
  bounds,            // THREE.Box3 for camera framing
  door,              // THREE.Vector3: outside the front door (apartments: the building entrance)
  exit,              // THREE.Vector3: where the character goes each day (lot edge + car, bus stop, sidewalk corner)
  path,              // THREE.Vector3[]: walkable waypoints door → exit
  plantSpots,        // THREE.Vector3[]: garden beds, pots (apartments: the chosen unit's balcony/lānai)
  animalSpots,       // THREE.Vector3[]: yard, coop, porch (apartments: balcony, for a cat)
  highlight(floor, unit),   // apartments/condos: glow a floor band or unit (no-op otherwise)
  pick(raycaster) → {floor, unit} | null,   // apartments/condos
  setNight(factor),  // window glow 0..1
  dispose() }
```

Generators:
- `buildingGen.generate({style, seed, kind: 'apartment'|'condo', settlement})` (task 35);
- `houseGen.generate({style, seed, variant: 'house'|'shared', palette, extras})` (task 37);
- `blueprintTo3d.build(blueprint, {style, palette})` (task 41).

`homeRender.js` (task 42) turns `state.home` into the right generator call, adds props for plants and animals, and returns the contract.

**Geometry rules**:
- Box, cylinder and extrude shapes only, with static geometry merged per material (`BufferGeometryUtils.mergeGeometries`).
- Windows are inset dark panels plus a glow material; walls don't need real holes.
- Blueprint walls are 0.5 ft thick and 9 ft tall. Doors are panels, 3 × 7 ft.
- **Roofs**: per room, each room gets its own gable/hip/shed/flat roof at one shared eave height. Don't attempt a
  straight-skeleton roof over the whole footprint; overlapping roofs are fine in this style.
- **Budget**: ≤ 150 draw calls and ≤ 120k triangles for a whole scene. A tree is ≤ 300 triangles, an animal ≤ 400.

## 6. Props (`three/props.js`)

Factories return `THREE.Object3D` with shared materials:
- `createPlant(kind, {healthy})` / `setPlantHealth(obj, healthy)`: potted plant, vegetable bed plants, flowers.
  Wilted means brown and drooping.
- `createTree(kind, {season})`: palm, banana, ʻōhiʻa-style, monkeypod, pine/spruce, maple, birch, oak, fruit (mango/citrus/apple/fig), cactus, agave.
- `createAnimal(kind)`: chicken, cat, dog, goat. Each has `.userData.idle(t)` for a small bob/peck/tail animation.
- `createGardenBed()`, `createCoop()`, `createCatchmentTank(gallons)`, `createSolarArray(kw)`, `createFence(points)`,
  `createCar(color)`, `createBusStop()`, `createMailbox()`, `createWoodpile()`, `createWindmill()`, `createStreetLamp()`,
  `createSlippers()` (a pair by the door: a small Hawaiʻi touch).
- Repeated vegetation uses instancing.

## 7. Character (`three/character.js`)

`createCharacter({shirt, pants, skin, hair}) → { object, walkTo(points, ms) → Promise, setVisible(bool), update(dt) }`
- A low-poly figure (~1.7 units = 5.6 ft tall): box or capsule body, sphere head, and limbs that swing with a sine walk cycle.
- It faces its direction of travel. Colors are seeded per player, with an option to change them in settings.

## 8. Dev galleries

Each gallery sets `document.body.dataset.ready = "1"` after its first frame renders:
- `?dev=scene&biome=<b>&t=<0..1>&month=<i>`: an empty lot, sky, terrain and landmark;
- `?dev=props`: every prop and animal in rows, healthy and wilted;
- `?dev=buildings&loc=<id>`: the three generated buildings for that location (`&all=1` shows one per location in a grid);
- `?dev=houses&loc=<id>&variant=house|shared`;
- `?dev=blueprint3d&template=tiny|cozy|family&loc=<id>`.
